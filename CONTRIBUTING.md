# Contributing to Haus-Suche

Thank you for your interest in contributing to **Haus-Suche**!  
We welcome improvements, bug fixes, documentation updates, and feature suggestions that help make the project better.

## Code of Conduct

By participating in this project, you agree to maintain a respectful, constructive, and inclusive environment for everyone.

## How to Contribute

You can contribute in several ways:

- Reporting bugs
- Suggesting new features
- Improving documentation
- Fixing issues
- Refactoring or improving code quality
- Enhancing UI/UX behavior

## Before You Start

Please take a moment to:

1. Read the `README.md`
2. Check existing issues and discussions
3. Make sure your contribution aligns with the project goals
4. Avoid duplicate pull requests or feature proposals

## Development Guidelines

When contributing code, please follow these guidelines:

- Keep the code clean, readable, and modular
- Follow the existing project structure
- Use meaningful names for classes, methods, and variables
- Avoid unnecessary complexity
- Make changes that are easy to review and maintain
- Prefer small and focused commits
